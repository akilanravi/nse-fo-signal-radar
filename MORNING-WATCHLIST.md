# Morning F&O Watchlist add-on

Add **only** the files from this ZIP to the root of your existing `nse-fo-signal-radar` repository. Do not replace `scanner.py`, `telegram.py`, `.github/workflows/scanner.yml`, or `.github/workflows/connection-test.yml`. No app settings are changed. This add-on ports the Next-Day Desk ranking from the uploaded toolkit and uses the existing scanner's read-only Dhan and one-bot Telegram helpers.

- Put `morning_watchlist.py` in the repository root.
- Put `morning-watchlist.yml` in `.github/workflows/`. If GitHub upload hides the dot folder, use **Add file → Create new file** and enter the full path.
- Reuses `DHAN_CLIENT_ID`, `DHAN_ACCESS_TOKEN`, `TELEGRAM_BOT_TOKEN_1`, and `TELEGRAM_CHAT_ID_1`. No new secrets. Ensure the Dhan token is current before the morning run.
- Go to **Actions → Morning F&O Watchlist → Run workflow → preview** to test. Preview prints the report in the job log without sending it. You can preview on a weekend, when it selects the next regular session and the previous completed session. Manual **live** sends only on a regular trading day between 08:00 and 09:00 IST.
- The weekday schedule triggers at **08:17 IST / 05:47 Saudi time**. GitHub can delay scheduled starts. The add-on skips configured NSE holidays, and does not start live outside the window. Update the existing `holidays.json` when the exchange publishes a new year's calendar.
- One runner downloads the current Dhan master and attempts every mapped NSE F&O **stock**, including stocks in all ten intraday groups. Indices are not ranked. The report shows validated versus total, and missing or incomplete session data is excluded. A partial report is labeled. If no stocks can be validated, no report is sent.
- The old watchlist filters are preserved: directional technical points at least 5, greater than the opposite side, volume ratio at least 0.8×, and price within 1.5 ATR of EMA21. Ranking uses 70 points technical, 15 relative volume, 15 proximity to EMA21. It is not the intraday 7/9 threshold. There are up to ten names per side, not a forced ten. Price levels are for the underlying, based on the prior session, not option premiums.
- News categories mirror the app: broad market/FII-DII headlines, per-stock Google News, and Moneycontrol discoveries. Telegram includes one link per category when retrieved, to keep the message manageable. Headlines are not independently verified or scored. The official NSE provisional cash-market FII/FPI, DII and combined net flows are included only when both are from the expected prior trading session. They are not stock-wise flows and do not alter the technical rank. If feeds are unavailable, the report says so instead of guessing.
- This is an alert-only research list. It never places orders. The pre-market workflow and manual preview are separate from live intraday scanning. Avoid launching a manual preview during a running live scanner session, since both use the same Dhan account limits.
